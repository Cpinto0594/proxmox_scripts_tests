# Postgres auth fails after Dokploy reinstall

**Cause:** `POSTGRES_PASSWORD_FILE` / `POSTGRES_PASSWORD` is only read during `initdb`. Reinstalling the app generates a new secret, but the existing named volume still has the old password.

## Fix A — restore the old secret

Recreate the secret with the original value (pull it from Infisical), redeploy with a full recreate.

## Fix B — reset the password from inside

Local socket connections use `trust`/`peer` by default in the official image:

```bash
docker exec -it <pg-container> psql -U postgres
```
```sql
ALTER USER <user> WITH PASSWORD '<new-password-from-secret>';
```

Then restart dependent apps.

## Prevention

Keep DB passwords in Infisical, not auto-generated by Dokploy, so a reinstall reuses the same value.
